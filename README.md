# Team Task Manager

Веб-приложение и Telegram-бот для управления задачами в команде с реальным временем обновления и уведомлениями.


## 🚀 Функциональность


### Веб-приложение
- ✅ Регистрация и аутентификация пользователей
- ✅ Создание и управление задачами
- ✅ Назначение исполнителей и сроков
- ✅ Real-time обновления через WebSocket
- ✅ Уведомления в реальном времени

### Telegram-бот
- ✅ Просмотр назначенных задач
- ✅ Отметка задач как выполненных
- ✅ Уведомления о новых задачах и дедлайнах

## 🛠 Технологии

### Backend
- **Django** + **Django REST Framework**
- **Django Channels** (WebSocket)
- **Celery** + **Redis** (фоновые задачи)
- **PostgreSQL** (база данных)

### Frontend
- **Pure JavaScript** (без фреймворков)
- **WebSocket API** для real-time
- **CSS3** с адаптивным дизайном

### Telegram Bot
- **Aiogram** 3.x (асинхронный)
- **REST API** интеграция
